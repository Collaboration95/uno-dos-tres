# Figure sources

These are snapshots of the existing local experiment outputs, committed so the README graphs can be rebuilt without retraining:

- `training-320.csv`: `ml/runs/uno/results.csv`; YOLO26n pretrained weights, 320px, 15 epochs, batch 32, MPS, seed 0.
- `training-256.csv`: `ml/runs/exp_n256/results.csv`; fine-tuned from the base checkpoint, 256px, 5 epochs, batch 64, `lr0=0.002`, `close_mosaic=2`, MPS, seed 0.
- `benchmarks.json`: `ml/runs/exp/results.json`, generated by `ml/experiments.py` and also summarized in `ml/results.md`.

Validation uses 1,500 synthetic scenes. The top-card proxy uses the first 600 validation images, skips images with no labels, and compares the largest labelled card with the highest-scoring prediction. CPU latency uses ONNX Runtime on the original development machine: one inference thread, five warmups, and the mean of 60 timed runs. The original logs do not identify its exact CPU model; these are historical desktop measurements, not phone benchmarks.

The training curves come from PyTorch validation after each epoch. The model sweep evaluates exported ONNX graphs separately, so its metrics differ slightly from the last training epoch. The figures do not establish accuracy on physical decks or real camera footage.

To regenerate all figures, generate the card PNGs with `npm run cards` at the repository root, then run `uv run python plot_docs.py` from `ml/`. The image grid is generated directly with `synth.make_image`, seed 0 and validation indices 0–7; it does not require the full dataset.
